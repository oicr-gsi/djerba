Expression percentiles compare the gene's expression in this sample, in transcripts per million (TPM), with TCGA tumours of the matching cancer type (or all TCGA tumours if no matching cohort is available) and OICR reference samples. Percentiles are reported only for genes present in the TCGA comparison data; genes without a match are reported as NA. Because TCGA libraries were poly-A selected and this test uses total RNA, percentiles are approximate, particularly for genes with low expression, and should not be used alone to infer overexpression.
